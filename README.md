# Ulgii Vietnam Travel Website

Static responsive website prepared for GitHub Pages.

## Files
- `index.html`
- `style.css`
- `script.js`

## GitHub Pages
After pushing to the repository:
1. Open repository Settings → Pages.
2. Set Source to **Deploy from a branch**.
3. Select `main` and `/ (root)`.
4. Save.

Expected URL:
`https://ulgiivietnam-del.github.io/ulgiivietnam/`

## Before publishing
Replace the placeholder contact details in the `#contact` section of `index.html` with the real Facebook URL, phone number, and email.
